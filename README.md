# Theme to Builder Converter (Theme2Builder)

Automated, 100% free web tool to convert ThemeForest HTML, View-Source, or web templates into native **Elementor Flexbox (`.json`)** and **Divi Builder (`.json`)** templates with 0 AI tokens.

## Features
- 🚀 **Drag & Drop HTML Upload**: Upload any theme HTML file or paste source code directly.
- ⚡ **Zero Token / $0 Cost**: 100% deterministic rule-based conversion engine.
- 📱 **Mobile & Desktop Responsive**: Works on any device (iOS, Android, Mac, Windows).
- 🧩 **100% Native Widgets**: Headings, Text Editors, Images, Buttons in Flexbox Containers.
- 📦 **1-Click Download**: Directly imports into WordPress Elementor Library or Divi Library.

## Local Development
```bash
npm install
npm start
```
Open `http://localhost:3000`

## Deploy to Vercel
Connect this GitHub repository to [Vercel](https://vercel.com) for instant automatic deployment.
